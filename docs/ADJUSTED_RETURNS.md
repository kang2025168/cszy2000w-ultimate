# 入出金调整后的收益

新版首次成功读取所有已配置账户时，保存新的初始净资产与已存在的现金流水 ID。旧快照不删除，但不再作为新收益曲线的本金。若当天部署并完成读取，就从当天开始；稍后部署则从实际首次读取时间开始，不能伪造今天的实时净资产。

后台每五分钟只读获取账户净资产、Alpaca CSD/CSW 现金流水，分页完整后写入 adjusted_return_points；同一账户 ID 只计算一次，包含 A。初始已存在的流水不重复加到本金。流水失败或账户映射改变时保留上一有效点并提示同步未完成。

调整本金 = 区间初始净资产 + 区间净入金。收益金额 = 当前净资产 - 调整本金。收益率 = 收益金额 / 调整本金；本金非正数时不显示百分比、不结算目标。曲线折线剔除净入金，标题金额仍显示真实净资产。

周、月、年及所有使用同一数据源；所有的本金从新起点累加净入金。周目标 5%、月目标 20%，使用 RETURN_GOAL_V3 独立记录期末成功和失败，不混入旧口径计数。没有足够历史快照或期末数据过旧时暂不结算。需保持后台服务运行积累数据。

入出金识别依据 [Alpaca Account Activities](https://docs.alpaca.markets/us/docs/account-activities) 的 CSD/CSW 与带正负号 net_amount；不将股票交易、分红归为入出金。非现金资产转入转出不在此现金流水口径内，需要另行核对。
