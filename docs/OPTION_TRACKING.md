# 期权模拟与收益记录

期权交易页新增“交易 / 收益记录”子菜单。先选择组合及组数，再点“模拟买入”；独立的 option_tracking / option_tracking_points 表保存组合与收益采样，不调用下单接口、不占用 D 资金。请求 UUID 用于防止相同请求重复记录。

模拟开仓按多头 ask、空头 bid；估算平仓按多头 bid、空头 ask。带符号净价之差乘以 100 和组数为收益，百分比以最大风险资金为分母，未扣手续费。报价缺失不补零，页面显示最后采样时间；采样时间不是报价时间。到期期权保留最后曲线并提示核对，不能当作最终结算。

后台每 5 分钟采样，页面关闭时继续记录。实际组合来自 Q 手动组合记录，先核实券商开仓单完全成交，以实际成交价建档；经确认的完整平仓单成交价用于结算收益。未完全成交开仓不计为持仓；部分平仓或缺失结算信息保留记录并提示核对。历史组合导入只能补开仓起点及现有估值，无法恢复未采集过的盘中曲线。

首次启动会自动创建数据表。部署更新 ultimate_v1 后启用；此模块不改变 Q 机器人卖出规则。
