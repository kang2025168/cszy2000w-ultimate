# 本次优化交付

## 已落地

- 成交确认统一读取订单回报；B 买入、加仓、卖出不再把账户总持仓变化当作本单成交。
- A 专属凭证不回退，key/secret 成对校验；配置读取失败阻断，增加券商账户 ID 校验、重复账户检测。
- 无有效密码拒绝启动网页；有期限随机会话、登录限速、JSON/Origin 校验、请求大小/连接时间/并发上限、安全响应头。
- 手动订单持久化幂等键、提交前资金预占、未知状态查询恢复、原子累计成交入账；共享账户的手动卖出按策略持仓限制。覆盖买卖、部分成交、空头回补与重复回报。
- 手动执行、B/F 调度、C 核心买入、D 网格和聚合持仓同步增加账户执行互斥；未核对的手动订单阻止聚合同步覆盖本地入账进度。
- D 网格持久化提交中状态、重启查询原订单、保留错误记录、订单预占；已启动轮次即使禁用新开仓也继续管理。
- F 候选更新限定目标策略；旧 D 强平复用幂等执行，未成交不清仓。
- 股票/策略组合唯一键迁移，避免同一股票不同策略互相覆盖。迁移不删除重复业务记录：数据冲突时失败并要求先处理。
- 版本化迁移与跨进程迁移锁，热路径每进程只检查一次。
- 有界数据库连接池、超时、按账户/线程复用券商客户端；网页使用后台快照；移除 dict.get 默认值造成的重复查询。
- 增加本进程 HTTP、DB、券商请求计数和 p50/p95，以及认证后的 /api/health。
- 网页模板移出 Python，B 参数独立成模块，手动策略保护规则与交易记录写入独立于网页服务。
- 去除机器人监管中的默认实盘时段强制覆盖；普通买入开关不再清除 emergency_stop；购买力读取失败禁止新开仓。
- 完整依赖版本锁、Docker/CI 使用锁文件、运行拓扑和配置文档更新、清理旧备份文件与忽略规则。

## 部署影响与边界

- 没有修改真实 .env、提交真实订单、运行生产迁移或重启现有交易容器。
- 上线需要迁移数据库，A 账户需专属凭证，看板需有效密码。宿主数据库和网页端口默认仅绑定本机，远程入口需按运行手册配置。
- 新执行日志覆盖手动股票与 D 网格；旧 A/C/F/B 等策略仍保留各自订单生命周期，本次没有把所有策略重写成同一个引擎。账户互斥不等同于全部策略已经具备相同的持久化恢复能力。
- 回归测试与模拟券商无法证明真实券商的所有边界行为；paper 端到端演练、生产备份恢复、HTTPS 代理、外部告警渠道和线上性能压测仍属于部署验收。
- 没有改动 B 策略收益阈值来迎合旧文档；文档现在反映原代码默认值，实际策略参数仍以部署环境覆盖为准。
- 保留提交状态不明订单的资金预占是明确设计：核对前不自动释放，不用重复下单掩盖网络故障。
