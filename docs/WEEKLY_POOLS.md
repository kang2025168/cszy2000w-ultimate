# B/C/D 周资金账本

A 独立。B/C/D 每周首次成功采集按共用交易账户净资产 40%/40%/20% 记下本金；按纽约日期周一切换。必须运行资金池服务才能采集，部署晚于周一时从首次成功采集时刻开始，不伪造周一行情。周末首次安装展示下周预估，周一再确定基准。

`weekly_pool_ledger` 按周持久保存初始快照、实际开始时间、最新各组净资产/盈亏；重启不会重置，旧周不删除。当前卡片展示本周，不触发持仓调仓或强制卖出。资金调用至少每分钟刷新一次，同一数据库各进程共用缓存和锁。

税费前股票盈亏 = 当前本组持仓市值 - 初始本组市值 + 基准后卖出实收 - 买入实付。使用券商 FILL 流水，按订单归属分组，同名股票分别以本组数量估值。B 和 A/C 做 T 新订单携带策略标识；历史订单仅使用已有明确记录。首次采集前成交排除，不重复计入旧收益。

净入出金按 40/40/20 增减各组本金，不计收益。新开仓预算按各自净资产乘现有风险系数；仍扣除持仓及挂单，保留券商购买力和策略开关限制。隐藏总览开关不改原启停状态。账户待归属损失还会约束合计开仓额度。

费用、融资利息、分红、未归类资产及期权盈亏暂列“账户待归属差额”，不伪装为某策略已核对利润。新增未知成交、期权成交、份额不一致或采集失败时，保留最后有效账本并暂停 B/C/D 新增额度，平仓逻辑不变。此版本不将未知成交按股票名字猜测分配，不包含实盘验证。未上线前的历史收益不补造。
