# 每日盈亏分析

统计页面默认显示美东当天，可选择数据库中已保存的日期。网页服务后台每 5 分钟采集一次，不依赖浏览器打开；仅在美东 04:00–20:00 采集，以避免券商晚间切换上一日权益口径。报告显示采集时间，不冒充官方最终日结。

`daily_pnl_reports` 以日期为唯一键：当天更新、往日保留，无自动删除。部署前数据不倒推；服务停止或数据源失败时保留最后一次成功报告，停机漏掉的日期不会伪造。数据库备份须包括此表。

范围为保证金交易账户，A 养老金不计入。账户净值变化包含出入金。股票当日估算公式：当前数量 ×（当前价−前交易日收盘价）＋卖出数量 ×（成交价−前收）−买入数量 ×（成交价−前收）。前收来自 IEX；实际成交来自券商 FILL 活动并分页去重，包含前日挂单今日成交。该值不等同于按成本核算的已实现盈亏，累计持仓浮盈亏另外显示；期权及缺失行情不按股票公式计算。

策略标签是当前数据库归属，不是成交归属凭证；同名跨策略时仍以逐股总贡献为准。未调整出入金、费用以及行情差异，不保证逐股估算合计等于账户净值变化。该模块不调用买卖、撤单或修改账户的接口。
